# Platform Engineer / Systems Engineer Search — 2026-08-01

**Search scope (per request):** Title = Platform Engineer or Systems Engineer (and close variants:
Data/AI Platform Engineer, Business/IT Systems Engineer, etc.). Hard filters only —
**(a)** local to the Bay Area OR remote, **and** **(b)** salary range hits $200k+ (or, for
consulting engagements, $75+/hr — none of the qualifying results this run were hourly-rate
consulting gigs; PwC's GenAI Systems Engineer roles are salaried consulting/advisory positions,
included under the salary threshold instead). No fit-based exclusion — background overlap is
used only to *rank*, not to filter.

Sources: `linkedin-search`, `builtin-search` (both directions — Bay Area query + remote query),
`freehire-search`, `muse-search`, `lever-search`, `remotive-search`, `levels-fyi-search`,
`ashby-search` (sector: tech), `greenhouse-search` (sector: tech). `workday-search` has no
"tech" sector defined (pharma/biotech only) so it was skipped as out-of-scope for this query.
Salary was pulled directly from the portal where shown (BuiltIn, Ashby); where not shown,
`detail` was fetched from LinkedIn/BuiltIn (CA/WA postings carry disclosed ranges by law) to
verify against the $200k bar before inclusion.

**31 postings passed the location + salary filter.** Ranked by background overlap
(Python/AWS/cloud platform engineering/agentic AI & Claude Code/GxP-adjacent systems
leadership), highest first; salary as tiebreaker.

## Portal coverage notes

- `workday-search` has no `tech` sector — only `pharma`/`biotech` — so it was skipped for this
  query as genuinely out of scope, not a failure.
- `muse-search` and `remotive-search` returned zero matches for these queries — Remotive's fixed
  ~34-job feed skews generalist remote (no platform/systems engineering roles in this run's
  snapshot) and Muse's `--query` is a local pass that found nothing in the pages crawled;
  neither looks degraded, just genuinely empty for this slice.
- freehire's `--facet salary_min=200000` combined with `-q` returned mostly unrelated postings
  (sales, clinical, executive roles) — the salary facet appears to override rather than combine
  with the local query filter. Not used for final inclusion; flagging as a possible skill/CLI
  quirk worth a closer look if freehire becomes a primary salary-filtered source going forward.
